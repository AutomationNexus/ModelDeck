# Home Assistant OS add-on

The ModelDeck HAOS add-on has moved to a dedicated repository:

**https://github.com/automationnexus/ModelDeck-HAOS**

## Install

1. **Settings → Add-ons → Add-on store → ⋮ → Repositories**
2. Add: `https://github.com/automationnexus/ModelDeck-HAOS`
3. Install **ModelDeck**, configure, **Save**, **Start**

Full walkthrough: [ModelDeck-HAOS docs](https://github.com/automationnexus/ModelDeck-HAOS/blob/main/docs/getting-started/haos-addon.md)

## Nightly testing

To test the HA add-on against ModelDeck `:nightly`, use the [nightly branch repository URL](https://github.com/automationnexus/ModelDeck-HAOS/blob/main/docs/getting-started/haos-addon.md#nightly-testing-only) documented in ModelDeck-HAOS. Stable installs should use the default repository URL only.

Shared guides (sensors, credentials, dashboard): [ModelDeck docs site](https://automationnexus.github.io/ModelDeck/)
